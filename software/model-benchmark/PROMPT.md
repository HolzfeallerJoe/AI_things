# Kickoff Prompt

Paste the text below verbatim as the first message to each model being benchmarked. Run it
in the directory containing `REQUIREMENTS.md` and `DELIVERABLES.md`.

---

```
Read the files REQUIREMENTS.md and DELIVERABLES.md in the current directory.

Implement the project specified in REQUIREMENTS.md completely, starting with its Section 0
setup, and produce every deliverable listed in DELIVERABLES.md.

All design and technology decisions are yours to make. You may ask me questions, but only
when a decision genuinely needs my input. Before asking, you must first explain: (1) the
problem in detail, (2) what each candidate solution would accomplish, and (3) exactly where
the candidates differ in ways that affect me — so that I can make an informed choice.
Never ask a question you could answer yourself through research or reasonable judgment.

Work until the project is complete as defined by the requirements and deliverables.
```
